# Changelog

## 0.1.4 - 2026-11-16

- Adapt compact layouts to viewer pane width while retaining the existing viewport fallback.
- Verify behavior on Obsidian 1.15.1 using isolated synthetic fixtures.

## 0.1.3 - 2026-10-25

- Cross-platform production build.
- Current Community installation documentation.


## 0.1.1

- Improved object list layout so type chips, object names, and row counts do not overlap in Obsidian.
- Removed the cramped internal height clamp from the Objects panel.

## 0.1.0

- Initial read-only SQLite viewer.
- Registered `.sqlite`, `.sqlite3`, and `.db` extensions.
- Added table, view, index, schema, source, metadata, preview, filter, refresh, and read-only query surfaces.
- Added SQLite fixtures and blocked-query tests.
